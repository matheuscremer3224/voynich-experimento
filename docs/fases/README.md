# As 18 fases

[← README](../../README.md) · [Diário](../../DIARIO.md)

Cada arquivo tem um resumo em linguagem simples e, em seguida, o texto técnico integral daquela fase.

| Fase | Título | Em uma frase |
|---|---|---|
| [1](fase-01.md) | Examinar a cena | Antes de ter qualquer teoria, medir tudo o que dá para medir no texto. |
| [2](fase-02.md) | Listar suspeitos | Três explicações concorrentes para o sistema de escrita, e a escolha de uma para testar a fundo. |
| [3](fase-03.md) | Montar a chave | Uma tabela de correspondências escolhida por um algoritmo, com regras fixas e congelada antes da leitura. |
| [4](fase-04.md) | Aplicar a chave | A chave congelada aplicada, linha a linha, a quatro trechos pedidos no desafio. |
| [5](fase-05.md) | O teste decisivo | A chave lê o texto embaralhado tão bem quanto o original. A hipótese S cai. |
| [6](fase-06.md) | Interpretação | O que dá para dizer do livro, separando o que veio do método do que é palpite. |
| [7](fase-07.md) | Veredito do desafio original | Confiança para a chave, a tradução e a interpretação, e o que derrubaria a hipótese. |
| [8](fase-08.md) | Os experimentos que ficaram em aberto | Onde o espaço cai, uma última chance para os silabários, e duas regras postas à prova. |
| [9](fase-09.md) | Tabelas por dialeto e mais três línguas | Uma tabela para cada dialeto e três línguas medievais novas: nada aparece. |
| [10](fase-10.md) | Significado ou texto sem língua? | Um 'falsificador' de seis regras imita quase tudo; só o agrupamento por páginas resiste. |
| [11](fase-11.md) | O texto acompanha as figuras? | Páginas com plantas parecidas não têm texto parecido. |
| [12](fase-12.md) | Os rótulos da farmácia nomeiam as plantas? | Os rótulos dos frascos e raízes não coincidem com as primeiras palavras das páginas de plantas. |
| [13](fase-13.md) | De onde vem o agrupamento por páginas? | O agrupamento é de vocabulário, não de grafia, e se estende por trechos de várias páginas. |
| [14](fase-14.md) | Síntese | O placar de todos os testes: o peso pende para um texto sem conteúdo linguístico recuperável. |
| [15](fase-15.md) | Um gerador honesto reproduz o agrupamento? | Sim: um gerador cujo vocabulário muda devagar de página em página chega perto do manuscrito em todas as medidas. |
| [16](fase-16.md) | E se for uma cifra com escolhas ao acaso? | Uma objeção séria, testada com uma versão simplificada da cifra Naibbe. |
| [17](fase-17.md) | Onde concordo e onde discordo do que foi feito em 2026 | Uma leitura crítica, com os dados do projeto, de um resumo sobre tentativas recentes com IA. |
| [18](fase-18.md) | A cifra Naibbe original, com agentes em paralelo | A cifra testada exatamente como o autor publicou não gera um texto como o do manuscrito, e um agente Cético pegou falhas no desenho do teste. |
